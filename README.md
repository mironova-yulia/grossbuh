# Гроссбух

Мини-приложение для Telegram: учёт аренды помещений.

Два файла:

- `index.html` — приложение, цифр внутри нет;
- `data.json` — все данные.

Четыре экрана: итоги за период, платежи арендаторов по месяцам,
задачи текущего месяца, взаиморасчёты по коммуналке.

Данные в репозитории — условные, для проверки интерфейса.
